# Security Policy

## Reporting a vulnerability

Please do not post credentials or details of an exploitable vulnerability in a
public issue. Use GitHub's **Report a vulnerability** feature for this repository
if it is available. Otherwise, contact the repository maintainer privately through
GitHub and ask for a secure reporting channel.

Include the affected version or commit, the impact, and steps to reproduce using
only accounts and systems you own or are authorized to test. Do not include live
tokens, passwords, or personal data; redact them from logs and screenshots.

## Exposed credentials

If a Discord token or provider API key may have been exposed, revoke or rotate it
with the provider immediately. Removing a credential from the latest commit does
not remove it from Git history or invalidate it.

## Scope and platform terms

Security reports are welcome for this project's code and its handling of secrets.
This project automates a Discord user account; see the prominent warning in the
README. A report or disclosure does not imply that the automation is permitted
under Discord's Terms of Service.
